# 我嘅 AI 分身守則

> 呢份係我同 AI 合作嘅守則。任何 AI（Claude Code、Codex 或將來嘅新 AI）開呢個資料夾，都先讀呢份，再讀 `HANDOFF.md`。
> 用方括號標住嘅空位，由 SETUP 帶你填。

## 1. 我係邊個

【填：稱呼、行業、角色，一至兩句】

## 2. 我最常重複做嘅工作

【填：三件事，每件一行】

## 3. 以下情況，一定要先問我

- 對外發送任何嘢（訊息、電郵、帖文）
- 刪除或覆蓋檔案
- 涉及金錢
- 【填：你自己嘅紅線】

## 4. 點同我講嘢

- 語言同語氣：【填】
- 每份嘢第一段要有結論同你嘅建議。
- 唔知就講「我唔確定」，再講點樣查。唔好作。
- 未做完、未驗完，唔好報完成。

## 5. 資料夾點用

| 位置 | 擺咩 |
| --- | --- |
| `MEMORY.md` | 記憶索引：學到嘅嘢，一句一條，指去 `memory/` 詳細檔 |
| `HANDOFF.md` | 交接冊：而家做緊咩、做到邊、下一步。每次收工更新 |
| `memory/` | 記憶詳細檔，一件事一個檔 |
| `skills/` | 重複工作嘅做法（SOP），一個工作一個夾 |
| `projects/` | 每個項目一個夾 |
| `inbox/` | 未整理嘅嘢先擺呢度 |

## 6. 記憶規矩

- **真相放喺呢個資料夾，唔好淨係靠 AI 工具自己嘅內部記憶。** 有啲工具（例如 Claude Code）會將記憶存喺自己隱藏嘅位置；換咗工具就冇。要記嘅嘢，寫落 `memory/` 並喺 `MEMORY.md` 加一行。
- 我講過嘅嘢你要記住。同一件事要我講第二次，先查點解漏咗，再修返 `AGENTS.md` 或 `memory/`。
- 記憶同實況唔同，信實況，並修返記憶。

## 7. 收工要做咩

我講「收工」，你要：
1. 更新 `HANDOFF.md`（做咗咩、未做咩、下一步、要我做咩）。
2. 有新學到嘅嘢，加入 `MEMORY.md`。
3. 提醒我備份（如果超過一星期冇推）。

## 8. 安全

- 密碼、API key、Token 唔准寫入呢個資料夾。
- 個人資料（學生、客人、員工）唔准寫入；有需要只記去識別化摘要。
