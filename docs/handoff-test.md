# 換 AI 接手測試

**目的：** 證明你嘅資料夾，換另一隻 AI 都讀得明。冇做過呢個測試，「換 AI 都唔驚」只係一個想法。

## 你需要

- 已經起好嘅 AI 分身資料夾（跟 SETUP.md）
- 兩隻 AI（例如 Claude Code 同 Codex），或者：一隻 AI ＋ 一個全新對話

## 步驟

1. 喺 Terminal 入你嘅資料夾：`cd ~/my-agent`
2. 開**另一隻** AI（原本用 Claude Code 就開 Codex，反過來都得）：
   - `codex`
   - `claude`
3. 逐字問呢三條，**唔好俾提示**：
   1. 「你讀到邊啲檔案？」
   2. 「我係邊個？我有咩紅線？」
   3. 「而家做緊咩？下一步係咩？」

## 評分

| 問題 | 通過標準 | 常見問題同改法 |
| --- | --- | --- |
| 1. 讀到邊啲檔案 | 講得出 `AGENTS.md`、`HANDOFF.md`（同 `MEMORY.md`） | AI 冇讀：check 有冇 `CLAUDE.md`／`AGENTS.md`，工具有冇喺正確資料夾開 |
| 2. 我係邊個、紅線 | 稱呼、角色同至少一條紅線都啱 | 答唔啱：`AGENTS.md` 第 1、3 節寫得太含糊，改具體 |
| 3. 做緊咩、下一步 | 同 `HANDOFF.md` 一致 | 答唔啱：`HANDOFF.md` 冇更新，或者寫得太籠統 |

## 結果

- **三條都過**：通過。將結果記入 `HANDOFF.md` 嘅「接手測試紀錄」。
- **有錯**：唔好怪 AI。通常係守則或交接冊寫得唔夠清楚。修好再測。修完再測仍然唔過，記低邊隻 AI 邊條唔過，呢個就係你要知道嘅「換 AI 嘅代價」。

## 幾時要重做

- 大幅改咗 `AGENTS.md`
- 每個月一次
- 準備轉用新 AI 之前
