# 本機 AI 分身起手包

> 將你嘅 AI 由「租嚟嘅腦」變成「住喺你部電腦嘅員工」。
> 換 AI、換帳號、換電腦，佢都記得你。
> by [Ronald Tse](https://www.instagram.com/ronald.tcf)（@ronald.tcf）

你有冇試過：同 AI 傾咗幾個月，教咗佢你嘅做事方法、你間公司嘅規矩、你鍾意嘅語氣。然後有一日——帳號出事、額度用晒、或者你想試另一隻 AI——一切由頭再嚟？

呢個包幫你做一件事：**將 AI 嘅記憶同工作紀錄，由 AI 公司嘅雲端，搬返落你自己部電腦一個資料夾。**

---

## 三十秒講明呢個包係咩

- **呢個包本身免費。** 你要先有 [Claude Code](https://claude.com/claude-code) 或者 Codex 其中一樣（兩間公司嘅訂閱要另計）。兩樣都有更好。
- **約二十五分鐘**，全程對話式。你將呢個 repo 嘅連結掉俾 AI，講一句「開始」，AI 會逐條問你問題，然後幫你起好個資料夾。
- 做完你會攞到**五樣**：
  1. 一個屬於你嘅 AI 分身資料夾（有規矩、有記憶）
  2. 一份寫俾 AI 睇、亦寫俾你睇嘅 `AGENTS.md`（你同 AI 嘅合作守則）
  3. 一本交接冊 `HANDOFF.md`（換 AI 時，新 AI 睇呢份就接得手）
  4. 一次「換 AI 接手」測試，證明換咗另一隻 AI，佢都讀得明你個資料夾
  5. 一個私人 GitHub 備份，部電腦壞咗都唔怕

**啱邊個？** 已經日日用 AI 做嘢、但唔寫程式嘅專業人士、老闆、老師、自僱人士。

**你需要先有（開始前檢查一次）：**

| 要有 | 點檢查 | 冇嘅話 |
| --- | --- | --- |
| Claude Code 或 Codex | 開 Terminal，打 `claude` 或 `codex`，見到 AI 應你 | 呢個包假設你已經裝好，先去官方裝 |
| Mac（Linux、Windows 嘅 WSL 都得） | — | Windows 原生（PowerShell）未測，可能行唔通 |
| 網絡 | — | 下載本包同備份都要連網 |
| `git` | 打 `git --version` | Mac 會彈出安裝視窗，撳「安裝」等幾分鐘 |
| `gh`（GitHub 指令工具）、GitHub 帳號 | 打 `gh --version` | **只係第 5 步備份先要**。冇都可以先做前 4 步，AI 會提你 |

## 點解要搬返落自己部電腦？

用一間公司嘅比喻：

> 你請咗個好能幹嘅員工。佢知道客人嘅脾氣、公司嘅 SOP、上個月傾到邊。
> 如果呢啲嘢**淨係喺佢個腦入面**，佢一走，你就打回原形。
> 但如果佢每做完一件事，都寫落**公司嘅交接冊同 SOP**，佢走咗，你請個新人，俾佢睇交接冊，兩日就接得手。

AI 都一樣。

```text
┌──────────────────────────────────────────────────────────┐
│                                                          │
│   ❌ 放喺 AI 公司雲端                ✅ 放喺你自己部電腦   │
│                                                          │
│   帳號一停、額度一冇、                資料夾喺你度，        │
│   服務一改，記憶跟住冇咗              換邊隻 AI 都讀得到    │
│                                                          │
│         AI 公司  ←──租用──  你         你 ──擁有──→ 資料夾  │
│                                        │                 │
│                          Claude Code ──┤                 │
│                          Codex ────────┤ 兩隻都讀同一個    │
│                          將來嘅新 AI ──┘                 │
└──────────────────────────────────────────────────────────┘
```

亦好似**攜號轉台**：換電訊商，你個電話號碼同通訊錄照舊。AI 分身嘅資料夾就係你嘅號碼同通訊錄，AI 公司只係電訊商。

### 就算帳號被停用，都唔使擔心咩？

**你嘅記憶同工作紀錄唔會冇。** 佢哋喺你自己部電腦，唔喺 AI 公司度。

你之後要做嘅係：開個新帳號，或者轉用另一隻 AI，叫佢讀返個資料夾，就可以接手。

但我要老實講兩個限制，唔想你期望過高：

1. **你仲係需要一隻 AI 用。** 資料夾保住你嘅記憶，唔等於你有 AI 可用。新帳號或另一間供應商，係要你自己搞掂。
2. **新 AI 接手，表現可能有少少唔同。** 佢讀得明你嘅交接冊，但每隻 AI 性格同強項唔同。所以呢個包有一步「接手測試」，等你**事先**知道會唔會順利。

詳細睇 [docs/why-local.md](docs/why-local.md)。

## 點開始

喺 Claude Code 或 Codex 入面，貼呢段：

```text
我係 AI 新手。請幫我跟住呢個 repo 嘅 SETUP.md，一步一步起我嘅「本機 AI 分身」：
https://github.com/ronaldtsecf/local-ai-agent-starter

重點：
1. 先用 `git clone` 將呢個 repo 下載去我電腦（例如 ~/local-ai-agent-starter），再完整讀入面嘅 SETUP.md 先開始，唔好跳步。
2. 每一步做之前，用日常廣東話講你要做咩、點解，等我講「好」先做。
3. 需要我作決定嘅嘢，逐條問我，講清楚你推薦邊個同原因。
4. 唔准將密碼、API key、學生或客人嘅個人資料寫入資料夾或者推上 GitHub。
```

（如果你已經 clone 咗個 repo 落電腦，喺該資料夾開 AI，講「跟 SETUP.md 開始」就得。冇 git 嘅話，去 repo 頁面撳 Code → Download ZIP，解壓後喺該資料夾開 AI。）

## 私隱同安全

- 呢個包本身唔會將你嘅資料傳去任何地方。你用嘅 AI 工具（Claude Code、Codex）同你揀嘅 GitHub 私人備份，就要跟返佢哋自己嘅規則。
- 備份只用**私人（Private）** GitHub repo。
- 密碼、API key、Token 放密碼管理器，**唔好放入資料夾**。
- 學生、客人、員工嘅個人資料，唔好放入 AI 分身資料夾；有需要就只放去識別化嘅摘要。
